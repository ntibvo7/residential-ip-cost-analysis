## 不限流量住宅IP分两种形态，先分清再花钱

“不限流量”在两种产品里含义不一样。独享住宅IP VPS 指的是套餐带宽内流量不计GB，跑多少都不另收费；代理池的“不限流量”通常指不按GB收费，但会改成按端口、按线程或按套餐来限制。带宽才是真正决定速度的东西——Nsocks 在产品页里专门强调“无IP限速”，侧面说明限速在这个行业里有多常见。

独享形态下，你拿到的是一台完整的VPS：IP归这一台机器专用，环境独立，想装指纹浏览器、跑自动化脚本都在同一台机器上做，不会出现“IP是住宅的、浏览器指纹乱跳”的错配。池子形态下，IP在池里轮换，每次请求拿到的可能是不同IP，多人共用同一个出口。

两种形态没有绝对好坏，区别在用途。后面用价格说话。
